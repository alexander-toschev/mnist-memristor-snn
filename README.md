# MNIST с мемристорными синапсами

Репозиторий сопровождает статью «Гибридная архитектура спайковой нейронной сети для распознавания MNIST с мемристорными синапсами». Здесь собраны материалы эксперимента по переносу обученных STDP-фильтров спайковой нейронной сети на мемристорный массив. Сравниваются распознавание по предварительно измеренным аппаратным откликам и результат симулятора при одинаковых весах, карте ячеек и цифровой части модели.

Автор: **А. С. Тощев**. Данные получены 23 октября 2026 года. Это репозиторий материалов, а не новая реализация управляющего программного обеспечения.

## Что проверено

Выполнены один аппаратный сбор и один сбор в симуляторе по одинаковой схеме размещения и с одинаковой цифровой частью сети. Оценка опирается на сохранённые измеренные отклики. Динамика LIF и классификатор рассчитывались цифровым способом.

## Результат

| Показатель | Реальный массив | Симулятор |
| --- | ---: | ---: |
| MNIST, тестовые изображения | 10 000 | 10 000 |
| Строгая точность | 64,48% | 65,52% |
| Точность при выборе максимального выхода | 64,50% | 65,54% |
| Принятые загрузки весов | 134/134 | 134/134 |
| Задания записи вне допуска | 828/3200 | 14/3200 |
| Повторное чтение без записи | 1 загрузка | 0 |

Использованы **24 физические ячейки**, образующие 12 дифференциальных пар в 10 измерительных блоках. Они последовательно представляли **1600 коэффициентов 64 фильтров 5 × 5**. Знаменатель 3200 — число заданий записи двух проводимостей для каждого коэффициента, а не число ячеек. Разность строгой точности — −1,04 процентного пункта. По одному сбору каждого вида нельзя оценить разброс между повторными опытами или приписать разность только ошибкам записи.

## Что вычислялось на массиве

Через [MemriBoard](docs/MEMRIBOARD.md) записывались проводимости, измерялось сопротивление и получались частичные взвешенные отклики на бинарные входы. Разность двух проводимостей кодировала знаковый вес. Измеренные отклонения сохранялись; идеальные веса не подставлялись вместо измерений.

Объединение частичных откликов, нейроны LIF и фиксированный классификатор выполнялись на CPU. Тест использовал заранее измеренные таблицы откликов. **Это гибридное распознавание по аппаратным измерениям, а не обращение к плате для каждой картинки и не аналоговая реализация LIF.** Фильтры предварительно обучались по STDP в симуляторе; нового обучения STDP на физическом массиве не было.

## Состав материалов

- `archives/` — четыре исходных архива: аппаратный сбор и его оценка, сбор в симуляторе и его оценка. Рядом с каждым находится неизменённая исходная квитанция JSON с размером, SHA-256 и перечнем файлов. Поле `archive` в квитанции указывает исторический путь в исследовательском репозитории.
- `data/COMPARISON.json` — точности, статистика и контрольные суммы сравниваемых модели и карты.
- `data/CELLS.csv` — карта всех 256 ячеек с основаниями включения и исключения. Не проверенные в этом переносе ячейки не объявляются неисправными.
- `data/map_qualified.json` — точная карта 24 использованных ячеек и параметры измерения блоков.
- `data/EVIDENCE.json` — связь выводов с первичными измерениями.
- `docs/REPRODUCIBILITY.md` — точные идентификаторы, протокол и команды повторной оценки.
- `verify.py` — проверка размеров и SHA-256 четырёх архивов без распаковки и выполнения кода из них.

| Архив | Назначение |
| --- | --- |

Архивы сбора содержат исходные ответы, параметры, программирование каждой загрузки, повторные чтения и конечное состояние выполнения. Архивы оценки содержат результаты классификации и сведения о входных данных. Подробный перечень — в соответствующей квитанции; байты исходных архивов не изменены.

## Получение и проверка

Нужны Git, Git LFS и Python 3.10 или новее. Скачивание ZIP с GitHub не заменяет получение LFS-объектов.

```text
git clone https://github.com/alexander-toschev/mnist-memristor-snn.git
cd mnist-memristor-snn
git lfs pull
python verify.py
```

## Повторная цифровая оценка

Код и модельные файлы находятся в [зафиксированной ревизии исследовательского репозитория](https://github.com/alexander-toschev/snn-memristor-hardware/tree/6f31f2421f43a9fbac3fb70c96328e4fe4b37e86). Это ревизия подготовки материалов; конкретные исходники запусков дополнительно идентифицированы в манифестах архивов. Для расчёта требуются PyTorch, BindsNET и совместимые штатные преобразователи MemriBoard; один публичный clone не гарантирует готовность всей среды.

Следующие команды выполняются в **отдельном checkout исследовательского репозитория**, а не в каталоге данного пакета. Они не обращаются к аппаратуре:

```text
git clone https://github.com/alexander-toschev/snn-memristor-hardware.git
cd snn-memristor-hardware
git checkout 6f31f2421f43a9fbac3fb70c96328e4fe4b37e86
git lfs pull
python -B tools/restore_terminal_session.py --session 4d2dfee0-3106-40de-9ad8-3d8542bef989
python -B experiments/mnist_tiled_transfer_20261022/experiment.py --evaluate-session 4d2dfee0-3106-40de-9ad8-3d8542bef989
```

Для симулятора в последних двух командах используется `673b05ce-6b5d-475f-b1b5-87f49f9f1e68`. Требуется конечное состояние `completed` и 10 000 тестовых изображений. Эти команды публикуются как инструкция; при подготовке данного пакета новый расчёт не запускался. Исходные архивы также лежат по историческим путям в зафиксированном исследовательском репозитории.

## Ограничения

Повторная оценка сохранённых откликов и независимый аппаратный опыт — разные задачи. Второй требует устройства, актуальной проверки карты и совместимой среды управления. Закрытые компоненты MemriBoard здесь не распространяются. Фактическая длительность программирующего импульса и ревизия конкретного чипа не подтверждены; полный набор версий исходной среды отдельно не установлен. Работа сети в реальном времени, физический LIF, энергопотребление и статистика независимых повторов не измерялись.
