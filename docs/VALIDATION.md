# Проверка поставки 8 ноября 2026 года

Проверен код этого репозитория с MemriBoard, установленным через pip как отдельный локально собранный wheel. Подключение через `vendor/`, внешний `sys.path` или динамическую загрузку модулей не использовалось. Исходники внешнего пакета и wheel в публикацию не входят.

| Проверка | Результат |
| --- | --- |
| Импорт внешнего Connector, converters, симулятора и CPU-зависимостей | Пройден; порт не открывался |
| `pip check` | Конфликтов зависимостей нет |
| SHA четырёх архивов | Совпали с квитанциями |
| Восстановление аппаратного / модельного сборов | 891 / 877 файлов проверены |
| 3 offline-теста | Полная раскладка 1600 коэффициентов в 134 загрузки; SHA модели и карты; граница относительных путей |
| CPU replay первых 16 изображений аппаратного архива | Спайки и предсказанные классы точно совпали с соответствующим префиксом сохранённой оценки |
| CPU replay первых 16 изображений модельного архива | Спайки и предсказанные классы точно совпали с соответствующим префиксом сохранённой оценки |
| Выходы классификатора в обеих smoke-проверках | Совпали при rtol=atol=10⁻⁶ |
| Пилот штатного симулятора | `completed`, одна загрузка 24 ячеек, MVM принят, 0/24 заданий проводимости вне допуска |

Пилот: 5020 обращений интерфейса, 316 команд записи, 9,78 с после начала сбора, без повторного чтения; 14 слабых бинарных откликов сохранены. Это проверка программной поставки, а не новая полная оценка MNIST. Физическая плата не использовалась. Все 10 000 изображений заново при этой проверке не рассчитывались; опубликованные 64,48% / 65,52% остаются результатами исходного опыта.

Условия: Windows, Python 3.11.9, NumPy 2.0.2, PyTorch 2.4.1+cu124, torchvision 0.19.1+cu124, BindsNET 0.3.3, SQLAlchemy 2.0.36. Вычисления выполнялись на CPU, несмотря на CUDA-вариант установленного PyTorch. Для читателя описана установка CPU-сборки; её полное воспроизведение на чистой ОС отдельно не заявляется.

Внешний пакет: локальная упаковка `memriboard-connector-local==0.0.0+135504d5dd8c`. Это идентификатор снимка исходников, не официальный номер релиза. Контрольные суммы публичных компонентов и сведения проверок находятся в `VALIDATION.json`.

Повторить offline-проверки:

```text
python -m unittest discover -s tests -v
python experiments/mnist_tiled_transfer_20261022/experiment.py --evaluate-session 4d2dfee0-3106-40de-9ad8-3d8542bef989 --smoke
```

Для нового идентификатора smoke-оценки, выведенного командой, сравнить с исходной полной оценкой:

```text
python tools/check_smoke.py --session SMOKE_UUID --reference d51aa091-91f8-4089-8767-1d91b82a9c14
```

`SMOKE_UUID` заменяется реальным идентификатором. Для модельной проверки исходный сбор — `673b05ce-6b5d-475f-b1b5-87f49f9f1e68`, архив полной оценки — `7c99d7c6-f345-4fea-a36f-e00eefd307b7`. Архивы предварительно восстановить по инструкции установки.
